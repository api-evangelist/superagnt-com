Superagnt provides a unified MCP server that delivers social data enrichment, web scraping, a PostgreSQL database, memory, file storage, queues, webhooks, and scheduling capabilities through a single API key. Agents can access LinkedIn, Instagram, TikTok, X (Twitter), YouTube, Reddit, Facebook, and web content, with usage metered per call. The platform offers SDKs, tools, and a developer portal for easy integration, plus tiered pricing and a no‑card trial.

**Areas:** MCP · Data Enrichment · Agent Toolkit · API Platform · Social Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for superagnt-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
